# MokkenLab Bibliography

**Complete APA 7th edition reference list of every source cited by
MokkenLab.**

Inside jamovi, each method-backed table cites its own sources in jamovi's
native numbered format (`jamovi/00refs.yaml` + `refs:`). jamovi's reference
renderer fixes that format and only shows it under `Table` results; it is a
constraint of jamovi's interface, not a choice of the module. Where the
report text names a source inline (e.g. "Koopman et al., 2022"), it says "see
references" instead of a bracket number, because jamovi assigns the number at
render time. This page is the authoritative APA 7th edition list
(CODE_STYLE.md §21): every key in `jamovi/00refs.yaml` appears here, and every
source cited in the report text appears in `jamovi/00refs.yaml`. The sources
of the bundled datasets are listed in `data/README.md`.

Every DOI below was checked against Crossref (title, journal, volume, issue,
pages and year) on 2026-11-04.
